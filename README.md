This project is a Java-based terminal program that:

Generates an NxN grid filled with random even numbers between 2 and 20

Allows the user to select a number (X) from the same range

Highlights all occurrences of X inside the grid

Displays count of how many times X appears

Handles invalid inputs, non-numeric values, and out-of-range numbers
How the Program Works
Step 1:

User enters a value N

Program generates an N × N grid of random even numbers

Grid is displayed neatly in aligned format

Step 2:

User selects a number between 2 and 20 (only even numbers)

All cells matching the selected number are highlighted like this:

[ 8]


Program counts how many times the selected number appears

Prints the updated highlighted grid and the count
